### 说明
- 这是我基于 liars_bar_llm 修修改改之后的得到的适合自己玩的骗子酒馆代码, 非常低技术力...目前还是个勉强能用的半成品, 也许有空会扩充一下.
- #### 功能概况
    - 允许 2-4 个人面对面地在电脑上玩骗子酒馆, 每人交替与程序交互, 程序自动发牌和判定.
    - 能够记录之前的游戏过程.
    - 提供了游戏记录的分析功能, 可以查看胜率, 开枪次数, 质疑成功次数等数据. 
- #### 代码描述
    - `game.py` 是游戏的主体, 直接运行即可开始游戏.
    - `game_record.py` 用于以 json 形式存储游戏记录, 保存在子文件夹 `game_records` 中. 这份记录只用于后期处理, 可读性不高, 不适合阅读. 该文件嵌套在 `game.py` 中调用, 无需手动运行. 
    - `json_convert.py` 用于将游戏记录从 json 形式转化为 txt 形式, 并使得内容更加可读, 保存在子文件夹 `converted_game_records` 中. 如果你想看之前的游戏记录, 运行 `json_convert.py`, 之后去对应子文件夹中阅读对应 txt 文件.
    - `game_analyze.py` 用于分析之前存储的游戏记录. 运行该文件会读取 `game_records` 中的所有 json 文件, 并打印出各个玩家的胜率, 开枪次数, 质疑成功次数等数据.
- #### 使用说明
    - 在开始游戏前, 你可以调整 `game.py` 结尾处的代码来自定义游戏人数和角色名称.
    ```python
    if __name__ == '__main__':
        players = ['player1', 'player2']
    ```
    当前默认的游戏人数为 2, 角色名称为 `player1` 和 `player2`. 修改 `players` 列表即可改变默认设置.
    - 为了确保各个角色的关键信息 (如手牌情况) 只有自己能看到, 在进行关键环节 (如出牌, 质疑等) 之前, 需要当前角色输入自己的角色名称进行确认, 才能进行相应操作. 请确保此时其他玩家无法看到屏幕上的内容.
